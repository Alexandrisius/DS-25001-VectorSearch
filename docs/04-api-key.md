# 04. Ввести API ключ OpenRouter

API ключ OpenRouter нужен для:
- генерации эмбеддингов (векторов для поиска)
- реранкинга (cross-encoder для улучшения результатов)

Без ключа поиск работать не будет.

## Получить ключ

1. Зайди на https://openrouter.ai/keys
2. Зарегистрируйся (через Google аккаунт)
3. Нажми **Create Key**
4. Скопируй ключ (начинается с `sk-or-v1-...`)

Пополни баланс: https://openrouter.ai/credits (минимум $5 хватит надолго).

## Ввести ключ через админку

1. Открой http://localhost:8000/admin
2. Войди: **admin / admin**
3. Слева выбери **Настройки**
4. Найди карточку **LLM API (эмбеддинги + реранкер)**
5. Заполни:

   | Поле | Что вписать |
   |---|---|
   | **Использовать LLM API** | ✅ Включи toggle |
   | **API Key** | Вставь `sk-or-v1-...` |
   | **Base URL** | Оставь **пустым** (для OpenRouter) |
   | **Модель эмбеддингов** | `qwen/qwen3-embedding-4b` |
   | **Модель реранкера** | `cohere/rerank-4-pro` |
   | **Размер батча** | 10 (по умолчанию) |
   | **Параллельные потоки** | 3 (по умолчанию) |

6. Нажми **Проверить подключение** — должно быть "OK! Размерность: 2560"
7. Нажми **Сохранить**

## Что выбрать

### Модель эмбеддингов

| Модель | Размерность | Когда выбирать |
|---|---|---|
| `qwen/qwen3-embedding-4b` | 2560d | **По умолчанию**, хороший баланс скорость/качество |
| `qwen/qwen3-embedding-8b` | 4096d | Лучше качество, медленнее |
| `openai/text-embedding-3-small` | 1536d | Дешевле, быстрее |
| `openai/text-embedding-3-large` | 3072d | Лучшее качество для английского |

**Если у тебя русский каталог** (КСР — классификатор строительных ресурсов) — бери **qwen3-embedding-4b** (хорошо работает с русским).

### Модель реранкера

| Модель | Когда выбирать |
|---|---|
| `cohere/rerank-4-pro` | **По умолчанию**, лучшее качество |
| `cohere/rerank-4-fast` | Быстрее, чуть хуже качество |

На OpenRouter других моделей реранкинга нет (только Cohere).

## Проверить что всё работает

1. Открой главную страницу http://localhost:8000
2. Введи запрос, например: `труба стальная`
3. Должны появиться результаты

Если результатов нет — смотри `make logs-api` на предмет ошибок.

## Частые ошибки

### "Неверный API ключ"
- Проверь, что ключ скопирован полностью (без пробелов в начале/конце)
- Проверь баланс на https://openrouter.ai/credits
- Попробуй создать новый ключ

### "Модель 'X' недоступна"
- OpenRouter мог убрать модель. Проверь список на https://openrouter.ai/models
- Попробуй другую модель из списка выше

### "Таймаут подключения"
- Уменьши **Размер батча** до 5
- Уменьши **Параллельные потоки** до 1
- Это лечит ошибки "No successful provider responses"
