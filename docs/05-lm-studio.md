# 05. Подключить LM Studio

LM Studio — приложение, которое запускает LLM локально (на твоём ПК).
Можно подключить вместо OpenRouter, чтобы не платить за API.

## Когда это нужно

- Хочешь **бесплатно** (без OpenRouter)
- Хочешь **полную приватность** (данные не уходят в интернет)
- У тебя мощный ПК с видеокартой (16+ ГБ VRAM)
- Готов потратить время на настройку

## Шаг 1. Установи LM Studio

Скачай с https://lmstudio.ai/ (Windows / Mac / Linux).

## Шаг 2. Скачай модели

Открой LM Studio → **Discover** (поиск) → скачай:

**Для эмбеддингов** (выбери одну):
- `text-embedding-nomic-embed-text-v1.5` (768d, лёгкая)
- `bge-m3` (мультиязычная, ~2ГБ)
- `mxbai-embed-large-v1` (1024d, хорошее качество)

**Для реранкинга** (если нужна):
- `bge-reranker-v2-m3` (~1ГБ)
- Или можешь **пропустить** реранкер — будет работать и без него (просто менее точно)

В LM Studio перейди на вкладку **Local Server** → должна быть кнопка "Start Server". Запомни порт (по умолчанию `1234`).

## Шаг 3. Запусти локальный сервер

В LM Studio:
1. Вкладка **Local Server** (иконка `</>`)
2. Сверху выбери **загруженную модель** (например `text-embedding-nomic-embed-text-v1.5`)
3. Нажми **Start Server**
4. Должен быть зелёный статус на `http://localhost:1234`

Проверь в браузере: http://localhost:1234/v1/models — должен вернуть JSON со списком моделей.

## Шаг 4. Настрой KSR Matcher

Открой http://localhost:8000/admin → **Настройки** → **LLM API**:

| Поле | Что вписать |
|---|---|
| **Использовать LLM API** | ✅ Включи |
| **API Key** | Любое (например `lm-studio`) — игнорируется |
| **Base URL** | `http://host.docker.internal:1234/v1` |
| **Модель эмбеддингов** | `text-embedding-nomic-embed-text-v1.5` (или как названа в LM Studio) |
| **Модель реранкера** | `bge-reranker-v2-m3` (или пусто, но качество ниже) |

Нажми **Проверить подключение**.

## Почему `host.docker.internal`?

Docker изолирует контейнеры от твоего ПК. `localhost` внутри контейнера = сам контейнер, а не твой ПК.

`host.docker.internal` — это магия Docker Desktop, которая указывает на твой ПК с LM Studio.

**Работает только на Windows и macOS.** На Linux нужно явно прокинуть порт.

## Если "Проверить подключение" возвращает ошибку

### "Endpoint не найден: http://host.docker.internal:1234/v1"
- LM Studio не запущен, или порт другой (посмотри в LM Studio какой порт)
- Вместо `host.docker.internal` попробуй IP: `http://192.168.1.X:1234/v1` (IP твоего ПК)

### "Таймаут"
- LM Studio медленно обрабатывает — увеличь `OPENROUTER_REQUEST_TIMEOUT` в `.env` и перезапусти

### "Модель не найдена"
- В LM Studio вкладка **Local Server** — сверху должна быть выбрана именно та модель, что ты указал в админке
- Имя модели должно **точно** совпадать с тем, что в LM Studio (без пробелов, с дефисами)

## Импорт данных с LM Studio

Когда нажмёшь "Импорт Excel" в админке, KSR Matcher отправит все тексты в LM Studio батчами по 10 штук. На средней видеокарте (RTX 3060+) обработка ~1500 строк займёт **5-10 минут**.

## LM Studio + OpenRouter вместе

Можно гибридно: эмбеддинги через LM Studio (бесплатно), реранкер через OpenRouter (платно). Просто заполни:

- **Base URL** = `http://host.docker.internal:1234/v1` (для эмбеддингов)
- **Модель реранкера** = `cohere/rerank-4-pro` (через OpenRouter)

**Base URL влияет на ОБА сервиса** (эмбеддинги и реранкинг), так что либо оба через LM Studio, либо оба через OpenRouter.

Если хочешь разделить — это надо дописывать в коде, скажи мне.
