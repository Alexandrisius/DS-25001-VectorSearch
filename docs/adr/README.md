# Architecture Decision Records

Лог архитектурных решений проекта KSR Vector Search v2.

**Формат:** нумерованные Markdown-файлы, по одному решению на файл. Каждый ADR содержит:
- Контекст (что за проблема)
- Решение (что сделали)
- Последствия (плюсы / минусы / что дальше)

**Именование:** `NNNN-short-slug.md`, где `NNNN` — четырёхзначный номер по порядку.

## Конвенция

- **Status** — одно из: `Принято` / `Отклонено` / `Устарело` / `Заменено ADR-NNNN`.
- **Коммит** — ссылка на git commit, в котором решение реализовано (если применимо).
- **Связано с** — обратные ссылки на другие ADR (если применимо).
- Не редактируем прошлые ADR задним числом. Если решение меняется — создаём новый ADR, который supersede'ит старый.
