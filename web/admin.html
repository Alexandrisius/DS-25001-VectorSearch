LLM API (эмбеддинги + реранкер)

Подключите OpenRouter или собственный OpenAI-совместимый сервер (LM Studio, Ollama, vLLM) для генерации эмбеддингов и кросс-энкодер реранкинга.

Использовать LLM API Все эмбеддинги и реранкинг через внешний сервис

OpenRouter: получите ключ на openrouter.ai/keys. Для LM Studio можно ввести любое значение (например lm-studio) — оно игнорируется.

Оставьте пустым для OpenRouter. Для LM Studio внутри Docker на этом же ПК используйте http://host.docker.internal:1234/v1.

Имя модели из OpenRouter или имя модели, загруженной в LM Studio.

На OpenRouter доступны только cohere/rerank-4-pro и cohere/rerank-4-fast.
